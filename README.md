This the Galaxy-Blast!
Galaxy-Blast is a simple space themed shooter designed to be like Space Invaders with the addition of the Y-axis.
Features include:
1. "Normal Mode" and a Harder "Master Mode"
2. Ammo and Health system
3. Settings Menu to adjust constants temporarily until game restart
4. Shop for buying "power-ups/boosts"
5. Sound Affects
BONUS: Light weight game play for any computer
